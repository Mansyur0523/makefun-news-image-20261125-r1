## Cara kerja

`main.ts` (Node stdlib-only) menyalin `entry.png` dari direktori repo ke
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`) setelah memvalidasi PNG
(magic 8 byte, ukuran ≤ 1 MiB, chunk IEND ada, CRC-32 tiap chunk cocok), dan
menolak menulis bila output jatuh di dalam repo.

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
